# IT VIP — ULTIMATE WINDOWS TOOLKIT

**Developer:** Mahmoud Basyouni Abdallah

هذا مشروع مصدر تراكمي لويندوز 10 و11 باستخدام C++17، ويحتفظ بالوحدات السابقة تحت هوية IT VIP.

## الوحدات المصدرية الموجودة
- `scanner.cpp`: فحص الملفات والبيانات الوصفية وSHA-256 حسب وظائف المصدر.
- `usb_guard.cpp`: أدوات سياسات USB مع وظائف الحماية/الاستعادة الموجودة في المصدر.
- `tempclean.cpp`: تنظيف الملفات المؤقتة.
- `activator.cpp`: قراءة حالة الترخيص وتشغيل مسارات التنشيط النظامية المتاحة؛ لا يحتوي مفاتيح ترخيص.
- `pwrecover.cpp`: إعادة تعيين كلمة مرور حساب محلي إداريًا، وليس استرجاع كلمة المرور القديمة.

## البناء
1. افتح Visual Studio 2022 Developer Command Prompt (x64 أو x86 حسب المعمارية المطلوبة).
2. نفّذ `build.bat msvc`.
3. أو استخدم MinGW مع `build.bat mingw` بعد ضبط `CXX` و`WINDRES`.
4. ملفات EXE الناتجة ستكون في `build\`.

يتم تحديد x86/x64 من بيئة المترجم التي فتحتها؛ لم يتم توفير حزمة ثنائية جاهزة لأن البناء لم يُنفذ على Windows داخل هذه البيئة.

## حدود الإصدار الحالي
- الواجهة الرسومية الحالية Win32 أولية وليست بعد تصميم Cyberpunk نهائيًا أو محرر VIP Studio مكتملًا.
- دعم Portable Apps ومسارات USB موجود بالمصدر ويحتاج اختبارًا فعليًا على Windows وفلاشات مختلفة.
- IT VIP Boot Manager المستقل لم يُنفذ بعد؛ لا يوجد bootloader ولا يجري تقسيم/تهيئة أي USB.
- بعض وحدات Shredder وعمليات ISO المتقدمة غير منفذة بعد.

**تحذير:** لا تشغّل أدوات تغيير السياسات أو إعادة تعيين الحساب إلا بعد قراءة رسائلها وفهم أثرها. لم يتم تنفيذ أي تغييرات على جهازك أو على أي USB.

## الواجهة الرسومية الأولية
أضيفت واجهة Win32 باسم `build/ITVIP.exe` إلى سكربت البناء. تعرض ملخصًا للنظام، وتتيح التبديل بين العربية والإنجليزية وتشغيل الوحدات الأصلية وفتح مجلد التقارير. بعض الوحدات الطرفية تحتاج معاملات صحيحة، والواجهة الحالية إصدار أولي وليست التصميم النهائي.

## البناء على Windows
افتح Developer Command Prompt الخاص بـ Visual Studio 2022، ثم نفّذ `build.bat msvc` من مجلد المشروع. لم يتم اختبار البناء على Windows في بيئة إعداد الحزمة الحالية.
