Implemented:
- Fast Copy cleanup is now limited to a destination root successfully created by the current worker.
  A create race cannot cause cleanup to delete a directory created by another process.
- Backup Center now fails closed on source enumeration, metadata, copy, SHA-256, manifest-write,
  and flush errors instead of silently skipping inaccessible files.
- Failed backup attempts remove only their own newly-created backup directory.
- Backup file copies use no-overwrite semantics inside the fresh backup tree.
- Restore continues to validate allowed relative paths, containment, file sizes, and SHA-256.
- Added source-contract tests and bilingual storage safety documentation/audit.
